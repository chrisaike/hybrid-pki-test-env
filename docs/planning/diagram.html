AWS Hybrid PKI Test & Certification Environment — Architecture

Cloud-first: the full production-representative PKI test environment is built in AWS first (View 1). The hybrid on-prem/VA integration is a follow-on extension (View 2). For leadership review.

AWS boundary Network / compute Key management Data / state Security / observability On-prem / VA

Root CA posture: offline (dedicated CloudHSM partition), signs only Intermediates + Root CRL — never attached to an online service. Ephemeral by IaC: entire stack is terraform apply/destroy; scheduled teardown drives idle cost to ≈ $0.

In Phase A–D the AD/GPO interface is a stubbed enrollment surface inside AWS. In Phase F we connect the real VA AD over Direct Connect/VPN and certify the cross-environment path with the same harness used for the AWS baseline.

Every issued leaf carries AIA (OCSP URL) and CDP (CRL URL) so revocation status is discoverable. The certification harness verifies the chain builds to Root and that OCSP/CRL reflect revocation.
